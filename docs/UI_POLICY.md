# UI変更方針

この文書はUIを新しく作り直すための仕様書ではなく、既存UIを変更するときの判断基準です。

- 現在のUIを基準とし、明示依頼なしに大規模な再設計をしない。
- 即売会のレジ操作では、大きな文字・大きな操作領域・一目で分かる会計状態を優先する。
- 一般的なPOSで慣れた配置や操作感は参考にしてよいが、特定製品の画面をそのまま複製しない。
- 既存レイアウトや見た目を変更する場合は、機能上必要な理由を明確にする。
- iPad等のタブレット横画面を主要利用形態として扱い、既存の実機操作性を悪化させない。
- 色だけに状態判別を依存させず、文字・形・状態表示も併用する。
- UI上の演出や装飾を、本番可否を左右する要件へ勝手に昇格させない。

意匠に関する調査資料は `docs/意匠チェック/` に置きます。法的評価と実装可否を同一視せず、必要な場合に個別に確認します。
