# event-pos 取扱説明書

この文書は当日の基本運用だけを記載します。使用しない機能の手順は本番条件ではありません。

## 1. 開場前

1. POS serverを起動する。
2. プリンターを使う場合はPrinterHostとTM-T70IIを起動する。
3. 当日使うレジ・顧客画面・管理端末から接続できることを確認する。
4. 運用ダッシュボードでDB、保存先、PrinterHost等、当日必要な項目に異常がないことを確認する。
5. プリンターを使う場合はテスト印字を1枚出し、日本語、金額、紙送り、カットを確認する。
6. 本番DBと成果物保存先が当日のものか確認する。

## 2. 開局

営業を開始し、使用する現金箱の準備金を金種別に登録します。

誤った営業日や現金箱で開始した場合は、そのまま販売を進めず確認します。確定済み記録をDBから直接削除して直しません。

## 3. 販売

商品を登録し、数量と金額を確認して支払を入力します。

現金では預り金と釣銭を確認します。外部決済を使う場合は、外部端末側の成功を確認してからPOSへ記録します。

年齢確認対象商品を販売する場合は、必要な確認を完了してから確定します。

会計確定後に印刷だけ失敗した場合、売上をもう一度確定しません。既存取引の印刷状態を確認し、必要な場合だけ再印刷します。印刷結果が不明な場合は、自動再送せず紙面の有無を確認します。

## 4. 入金・出金

両替補充等、売上以外で現金箱の残高を変える場合は入金・出金として登録します。箱の現金だけを動かして台帳をずらさないようにします。

## 5. 中間点検・精算

必要なタイミングで金種別実在高を数え、理論現金との差を確認します。

精算後は、SQLite backup、xlsx、manifest等の成果物状態を確認します。成果物生成だけが失敗した場合、確定済み点検・精算をやり直さず、同じ確定記録から再生成します。

## 6. 返品

元取引がある場合は取引を検索し、内容と理由を確認して全部返品を登録します。元売上は書き換えず、返品取引として追記されます。

レシートがない例外返品も登録できます。

部分返品専用処理はありません。必要な場合は全部返品後、残す商品を新規売上として登録します。

外部決済の実返金は決済端末側で行い、POSは結果を自動取得しません。

## 7. 終了

- 精算状態を確認する。
- 未解決の印刷jobがないか確認する。
- backup/xlsx/manifestの生成結果と保存先を確認する。
- 過不足や返品等、引継ぎが必要な内容を記録する。

SQLite、WAL、成果物を営業中に手作業で移動・上書きしません。
