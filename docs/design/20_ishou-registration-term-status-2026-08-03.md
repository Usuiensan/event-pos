# UI意匠登録の存続期間チェック（2026年8月3日時点）

## 1. 結論

`docs/意匠チェック` にある102件の意匠登録資料を、記載された出願日・登録日と特許庁の存続期間の説明に基づいて確認した。

したがって、2026年8月3日現在、上記10件は「意匠権の存続期間満了により、登録意匠権だけを理由に模倣禁止を主張しにくい候補」である。

ただし、これは公報に記載された日付からの機械的判定であり、J-PlatPatの原簿・登録料納付状況・移転・放棄等を確認した確定的な権利状態ではない。

## 2. 判定方法

- 2020年4月1日以降の意匠登録出願は、原則として出願日から最長25年。
- それ以前の出願は、今回の資料の判定では登録日から20年を目安にした。
- 2005年登録の10件以外は、記載された登録日から20年または出願日から25年をまだ経過していないため、期間満了候補には分類しなかった。
- 旧制度の関連意匠は本意匠と同じ登録日のグループとして確認した。個別の権利状態は各登録番号ごとに確認が必要である。

特許庁は、2020年4月1日以降の出願について、意匠権の存続期間を出願日から最長25年と説明している。

- https://www.jpo.go.jp/system/design/gaiyo/seidogaiyo/torokugaiyo/index.html
- https://www.jpo.go.jp/system/process/tesuryo/kaisei/2020_ishoryokinkaisei.html

## 3. 「真似しても大丈夫」の範囲

上記10件について、期間満了が原簿で確認できれば、少なくとも当該登録意匠権については、現在のevent-posのUI設計を制約する根拠は原則としてなくなる。

ただし、次は別途確認が必要である。

1. 後年の関連意匠・別登録が同じUI表現を保護していないか。
2. 同じ画面表現について商標、著作権、不正競争防止法その他の権利・主張がないか。
3. 画面画像、ロゴ、商品画像、固有の文言をそのまま転載していないか。
4. 期間満了前の別登録（特に2010年以降のPOS・情報画像登録）と類似しないか。

したがって、上記10件の図面を参考にしてPOSとして自然な配置や大きな文字を採用することは、他の存続中の登録と重ならない範囲では許容しやすい。一方、後年登録された、返品、会計、テンキー、カレンダー、進捗表示、情報管理の画面表現まで自由になるわけではない。

## 4. event-pos向けの扱い

### 利用しやすくなった可能性があるもの

- 2005年の店員向けPOS画面の大枠
- 2005年のセルフチェックアウト画面の大枠
- 2005年登録群に現れる商品明細、合計、操作欄の配置を参考にした操作設計

### 依然として慎重に扱うもの

- 2010年以降のPOS、カード決済、セルフレジ関連画面
- 2020年以降の「商品登録用画像」「情報表示用画像」「情報入力用画像」
- 返品切替、会計テンキー、カレンダー吹き出し、操作サポート矢印、進捗ステータスバー

操作性のために、明細・合計・会計操作の大枠を維持すること自体を避ける必要はない。差別化は、存続中の登録図面と一致しやすい具体的な線、色、ボタン配列、モーダル形状、状態表示の組合せを中心に行う。

## 5. 未確認事項

- 各登録番号のJ-PlatPat原簿による現在の権利状態
- 登録料の未納による途中消滅の有無
- 個別の関連意匠の存続期間・分離状態
- 意匠権以外の権利・不正競争防止法上の問題
- event-posの各実画面との正式な類否判断

本書の「期間満了候補」は、実装方針を決めるための一次スクリーニングであり、公開・販売前の最終的なFTO（実施自由）確認の代替ではない。
