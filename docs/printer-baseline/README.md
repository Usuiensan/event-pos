# プリンター比較基準

Discord botが稼働するDebian環境から、Windows実機試験の比較資料を保存する。

## 保存するもの

- `discord-printer-bot` の移植元commit SHA
- TM-T70IIの接続情報と設定
- OS、CPU、driver、USB device情報
- 同一fixtureから生成したESC/POS bytesとSHA-256
- 印字したレシートの写真またはscan
- 日本語、円記号、画像、バーコード、紙送り、部分カットの結果
- 紙切れ、カバー開、USB切断、再接続時のログ

秘密情報、Discord token、個人情報は保存しない。
