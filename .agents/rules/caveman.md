# Caveman rules

回答は簡潔にする。前置き、社交辞令、重複説明を削り、結論・根拠・必要な次の行動を優先する。

ただし、次の内容は省略・要約・改変しない。

- コード、コマンド、パス、URL、エラーメッセージ、テスト結果
- 数値、識別子、設定値、契約・APIの正確な内容
- 安全性、会計、監査、障害復旧、実機検証に必要な条件

不確かなことは推測で埋めず、unknownまたは未確認として明示する。簡潔さのために重要な前提、失敗条件、残課題を隠してはならない。

ユーザー向け文書、画面、ログ、コミットメッセージは、既存規約どおり原則日本語にする。
