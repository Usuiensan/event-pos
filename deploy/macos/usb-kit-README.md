# macOS USBキット

USB内の `Start-USB-Kit.command` をダブルクリックします。Terminalウィンドウ1つでPOSとPrinterHostが起動し、ブラウザーが開きます。Node.jsやDockerの事前インストールは不要です。

- 初回はイベント情報を入力します。商品一覧は空で、管理者の責任者番号は `001` です。
- Epson TM-T70IIを使う場合はMacにUSBで接続します。プリンター設定は `printer-host.env` にあります。
- 会計はMac側のSQLite DBへ確定時に保存します。稼働中は5秒ごとに変更を調べ、変更があれば確定済みDBをUSBへ保存します。
- USBが抜けた場合、Mac側に保存済みの会計は残ります。TerminalにUSBへの保存エラーが表示され、同じUSBが元の場所に戻ると自動保存を再試行します。ブラウザーの画面や設定など、USB上のファイルを使う操作にはUSBの再接続が必要です。
- 終了時はTerminalで Ctrl+C を押し、DBをUSBへ書き戻した表示を確認してからUSBを取り出します。USBだけで復旧する場合は最後に完了した保存時点までです。
- 通常のシャットダウン・再起動で終了通知を受け取ると、macOSに最長10秒の猶予を求め、POSを止めてUSBへの最終保存を試みます。Terminalを閉じた場合も、終了通知を受け取ると最終保存を試みます。
- スリープ通知を受け取ると、最長5秒を目安に未同期のDBをUSBへ保存します。POSは稼働したままで、復帰後も使えます。スリープ前にUSBへ保存できなかった会計データはMac側に残り、復帰後に自動保存を再試行します。
- 強制終了や電源断の後は、**同じMac、同じmacOSユーザー、同じUSB**で起動してください。PCに残ったSQLite DBの整合性を確認し、確定済みのデータをUSBに書き戻してから起動します。
- 書き戻しが完了するまで、別のPCではこのUSBを使えません。ローカルDBとログは `~/Library/Application Support/EventPos/UsbKit` にあります。

端末と同じアーキテクチャ向けにビルドしたキットを使用してください。Apple Siliconはarm64版、Intel Macはx64版です。
